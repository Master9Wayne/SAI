# SAI Corpus Sources

SAI indexes only the verified education software SDLC corpus under `docs/ingested/education/`.

| Source set | Local evidence | Application |
| --- | --- | --- |
| Official public project documentation for Moodle, Open edX, Sakai, Kolibri, Oppia, Canvas LMS, OpenBoard, and BigBlueButton | `docs/ingested/education/education-software-sdlc.md`, `education_software_sdlc.json`, and `source_index.json` | Comparative evidence for education requirements and SDLC recommendations |

The corpus contains eight projects and 57 source entries. A named SDLC methodology is reported only when the cited project documentation explicitly supports it. Otherwise, SAI reports documented lifecycle activities without relabeling them. Public documentation is evidence of documented practice, not proof of undocumented internal execution.

SAI marks missing jurisdiction, child-safety, privacy, accessibility, institutional-policy, procurement, and retention details as `NEEDS-VALIDATION`. Final requirements and SDLC decisions require human review.
